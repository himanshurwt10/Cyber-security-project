# 🖥️ Network Device Monitor

A Python-based desktop application that scans a local network and monitors connected devices in real time.

This project was developed as part of my **Cybersecurity Internship at DRDO (Defence Research and Development Organisation)** to gain hands-on experience in network scanning, device monitoring, and cybersecurity concepts.

## ✨ Features

- 🌐 Automatically detects the local network
- 🔍 Scans connected devices using ARP (Scapy)
- 🖥️ Displays IP Address, MAC Address, Vendor, and Hostname
- 🟢 Detects Online devices
- 🔴 Detects Offline devices
- 🆕 Identifies newly discovered devices
- 🔄 Automatically refreshes the device status
- 🔍 Search functionality for quick device lookup
- 📄 Export scan results to CSV
- 🖥️ Simple and user-friendly Tkinter GUI

## 🛠️ Technologies Used

- Python
- Scapy
- Tkinter
- Socket
- CSV
- Threading
- mac-vendor-lookup
